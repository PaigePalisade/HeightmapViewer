An implementation in C of the alorithm used in the Voxel Space game engine from the classic Comanche video games.
https://en.wikipedia.org/wiki/Voxel_Space

Using CPU driven rendering and the Raylib graphics API

To build and run, Raylib must be installed on the system e.g. `sudo dnf install raylib-devel` on Fedora Linux
https://www.raylib.com/
